# Portfólio Profissional | Stephanie Souza Miranda

Portfólio web criado para apresentar meu currículo, minhas habilidades e meus projetos, em busca de uma oportunidade de estágio em programação.

🔗 **Acesse o site:** [https://xstephaniexsouzax.github.io/]

## Sobre o projeto

Desenvolvi este portfólio para praticar os conhecimentos básicos em HTML, CSS e JavaScript e para reunir, em um só lugar, minha trajetória profissional, incluindo experiências de outras áreas, e meus projetos de tecnologia.

## Funcionalidades

- Layout simples, moderno e responsivo (celular, tablet e computador)
- Foto circular no cabeçalho
- Saudação que muda conforme o horário (bom dia, boa tarde ou boa noite), feita com JavaScript
- Seções: Objetivos, Habilidades, Experiências, Projetos e Contato
- Destaque para a promoção na experiência atual

## Tecnologias utilizadas

- HTML5
- CSS3 
- JavaScript
- GitHub Pages (publicação gratuita)

## Como executar localmente

1. Baixe o projeto (botão **Code > Download ZIP**) e extraia a pasta.
2. Abra o arquivo `index.html` no navegador.
